# Post-Analysis Iteration

> Moved verbatim out of `SKILL.md` (v3.1.0 body) so the body fits the 500-line / 5,000-token budget. Text unchanged.

---

### If Go / Cautious Go:

```markdown
Based on the analysis, recommended next steps:

1. **Validate:** [Specific action to confirm key assumptions]
2. **Quick Win:** [First thing to do immediately]
3. **Deep Dive:** [What else to investigate]

Options to continue:
- [ ] Explore [specific segment] deeper
- [ ] Analyze [specific competitor] in detail
- [ ] Research funding/startup ecosystem
- [ ] Create action plan
- [ ] Export as document
```

### If No-Go:

```markdown
This idea has significant challenges. Alternative directions:

**Pivot Options:**
- Different segment: [suggestion]
- Different model: [suggestion]
- Different market: [suggestion]

**Related Opportunities:**
- [Alternative 1]
- [Alternative 2]

What interests you - pivot the current idea or explore alternatives?
```

### If Data is Missing:

```markdown
For a confident decision, additional data needed:

**Primary Research (you would conduct):**
- [ ] Interviews with [target group] — suggest 5-10
- [ ] Survey about [specific question]
- [ ] Mystery shopping at [competitors]

**Secondary Data to Find:**
- [ ] APR financial data for [specific competitors]
- [ ] [Specific report or statistic]

I can provide frameworks for conducting this research. Want them?
```
